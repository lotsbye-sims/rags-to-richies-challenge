# Rags to Riches Starter

A random challenge starter for The Sims 4. One Sim, an empty lot and §0. It rolls the Sim (traits, aspiration, career, side hustle), the world and lot, a few twists that make the start harder, and the goal that ends the challenge. The rules sheet has a setup checklist and house rules you can switch on or off.

The whole tool is a single `index.html` file, with nothing to install and no server. Open it in a browser or turn on GitHub Pages.

All the data (names, traits, careers, twists, goals, rules) sits in plain lists at the top of the script in `index.html`, so it's easy to change or add to.

Unofficial fan-made tool, not affiliated with or endorsed by EA.
